# 软件工厂统一 WebUI

运行在 DeepSeek Harness（DSH）网页中的软件工厂前端插件，提供能力概览、Agent 注册与修改、Agent 编排，以及聊天中的执行进度与结果卡片。

**普通用户请下载 Releases 中的预编译安装包，按下面的快速启动步骤安装。源码下载 ZIP 不等于插件安装包。** 本项目依附 DSH 运行，没有独立网站、独立启动命令或自己的数据库连接配置。

## 功能

- **软件工厂概览**：查看和搜索能力树、逻辑 Agent 与具体版本；支持树与画布联动、缩放、节点详情和可拖动分栏。
- **软件工厂入库**：按字段元数据展示八大类注册字段，支持草稿、已有版本修改、逻辑资料修改及保存前预览。当前数据库基线为 19 项字段，逻辑描述与版本描述独立。
- **原生 AI 辅助**：沿用 DSH 的聊天、模型选择和附件功能，帮助整理草稿；数据库写入由 Manage 后端校验并要求人工确认。
- **Agent 编排**：专用聊天入口、候选审核、人工改选、执行模型选择与确认执行，需要对应编排后端。
- **执行卡片**：显示当前阶段、已上报进度、消息、取消操作、最终交付下载和中间材料目录；支持恢复聊天中的历史任务展示。不提供暂停功能。

WebUI 负责展示和用户操作。查询、审批、编排与算法执行分别由对应后端负责；某个后端不可用时，相关功能会提示未就绪。

## 环境与配套插件

当前开发目标为 **DSH 0.2.1-alpha.2、Node.js 24 或以上**，Cordis peer 版本为 `4.0.5-alpha.1`。其他 DSH 版本需另外核对兼容性。

| 使用场景 | 需要准备的服务 |
| --- | --- |
| 浏览能力、Agent 和版本 | Gateway，包版本声明为 `^0.1.1`，读取接口 API 1.0 |
| 注册、编辑、AI 辅助草稿与人工保存 | Gateway + Manage，Manage 包版本声明为 `^0.1.0`，含其安全预设 |
| 查看执行进度、取消及下载结果 | Runtime；实际执行还需安装对应业务插件 |
| 使用 Agent 编排 | Orchestration 及其所需的 Gateway、Runtime、业务插件和模型配置 |

WebUI 当前清单将 Gateway、Manage 声明为 peerDependencies；缺少时安装器可能报告依赖问题。页面层面的降级提示不等于安装器会忽略 peer 校验。安装时应先准备这两个插件。Runtime、Orchestration 按需准备。

HugeGraph 的服务地址、认证和数据准备按照 Gateway、Manage 的说明操作，数据库只由后端连接。**WebUI 不需要 `.env`，也不要向前端填写数据库密码。** AI 和算法所用模型由 DSH 及对应后端配置。

## 新电脑快速启动：使用预编译包

### 1. 准备宿主和后端

1. 安装并启动兼容版本的 DSH，确认其原生网页可以正常登录，且侧栏有“插件”管理入口。
2. 按 Gateway、Manage 各自的文档准备 HugeGraph 连接与安全配置，安装并启用后端，确认健康状态。只有 WebUI 包不能创建或恢复软件工厂数据库。
3. 如需编排、执行功能，再安装并启用 Runtime、Orchestration 和真实业务插件；需要模型时先在 DSH 中配置 provider/model。

本 README 从 DSH 已正常运行开始说明；宿主安装及启动命令以该 DSH 发行版说明为准。

### 2. 下载并解压 WebUI

从本仓库的 **Releases／发布** 下载 `software-factory-webui-0.1.0.zip`，解压到一个长期保留的目录，例如：

```text
D:\DSH-Plugins\software-factory-webui\
├── package.json
├── cordis.patch.yml
├── README.md
├── icon.svg
├── lib\
└── locale\
```

以**包含 `package.json` 的目录**为准；解压后如果多了一层文件夹，继续进入内层。使用预编译包不需要安装源码开发依赖、执行构建或启动额外前端服务；DSH 安装器仍可能解析包依赖，因此不承诺完全离线安装。

尚未发布 Release 时，请联系维护者获取预编译 ZIP 或完整运行目录。

### 3. 在 DSH 网页安装

1. 打开“插件 → 添加插件 → 安装第三方插件”。
2. 安装来源填写上述目录的绝对路径，例如 `D:\DSH-Plugins\software-factory-webui`。这是 **DSH 服务端电脑**上的路径，浏览器电脑上的路径不能代替服务端路径。
3. 安装完成后启用组合包及 `sf-webui` 插件条目，确认没有激活错误，再刷新网页。
4. 侧栏应出现“软件工厂概览”“软件工厂入库”和“Agent 编排”入口。分别打开需要的功能检查后端连接。

本地目录安装需要保留安装目录，不要安装后删除、移动或改名。不要同时启用已经包含 WebUI 的聚合 Bundle，以免重复注册相同插件。

### 4. 验证可用

- 概览：能够显示真实能力树，选择 Agent 或版本后能看到详情。
- 入库：能够读取字段和创建草稿；仅浏览和填写不会自动写数据库。确认需要保存的变更后，再进行人工预览与保存。
- 编排与执行：配套后端已启用时可进入编排聊天；执行卡显示后端上报的进度。验证安装无需默认运行耗时算法。
- 下载：存在真实任务时，检查最终交付下载和中间目录打开功能；目录打开还取决于宿主部署方式和权限。

**能够显示页面不等于所有后端就绪；安装成功也不等于数据库、模型或业务算法已验证。**

## 更新与停用

- **更新**：按发布说明替换安装文件，重启 DSH，再按 `Ctrl+F5` 刷新网页；需要时同步更新配套后端。
- **停用／启用**：在 DSH“插件”页操作，重新启用后刷新网页。停用 WebUI 不会取消后台任务，也不会删除数据库、草稿或历史产物。
- **保留目录**：按本地目录安装后，不要删除、移动或改名该目录。

## 遇到问题

- **页面未出现或仍是旧版**：检查 `sf-webui` 是否启用，避免和聚合 Bundle 重复启用；重启 DSH 并强制刷新。
- **提示后端未就绪**：检查对应的 Gateway、Manage、Runtime 或 Orchestration 是否已安装并正常启用。
- **登录或下载失败**：重新登录 DSH，检查当前用户权限和 Runtime 状态；仍有问题时向维护者提供报错信息。
